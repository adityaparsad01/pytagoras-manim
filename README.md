# Pythagorean Theorem with ManimGL

A visual explanation of the Pythagorean theorem using the original ManimGL engine used by 3Blue1Brown.

Files:
- pythagorean.py: animation scene
- narration.txt: voice-over script
- render.sh: local/headless render and audio mux
- .github/workflows/render.yml: GitHub-hosted render workflow

The final video is dist/pythagorean_theorem.mp4.

Official ManimGL source: https://github.com/3b1b/manim
