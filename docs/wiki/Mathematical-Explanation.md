# Mathematical Explanation

## 3-4-5 example

For a right triangle with:

- a = 3
- b = 4
- c = 5

the theorem gives:

**3² + 4² = 5²**

Therefore:

**9 + 16 = 25**

## General area proof

Place four identical right triangles inside a larger square with side length **a + b**.

The large square has area:

**(a + b)² = a² + 2ab + b²**

The four triangles together have area:

**2ab**

The remaining center is a square whose area is:

**c²**

Therefore:

**a² + 2ab + b² = c² + 2ab**

Cancel **2ab**:

**a² + b² = c²**
