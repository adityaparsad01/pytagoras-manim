# Project Overview

## Goal

Create a clear visual explanation of the Pythagorean theorem using ManimGL.

## Main files

| File | Purpose |
|---|---|
| `pythagorean_v2.py` | Main animation scene |
| `narration.txt` | Narration script |
| `audio/final_audio.mp3` | Final narration audio |
| `render.sh` | Rendering and audio-mux pipeline |
| `.github/workflows/render.yml` | GitHub Actions renderer |
| `dist/pythagorean_theorem_v2.mp4` | Final rendered video |

## Technology

- Python 3.12
- ManimGL
- FFmpeg
- Xvfb
- GitHub Actions
